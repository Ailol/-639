## Audit rules

1. **Source:** link a concrete repo, path or commit, not a claimed hidden mechanism.
2. **Scope:** distinguish user-authored work, imported templates, copied projects, and third-party upstream history.
3. **Readiness:** label each claim PROPOSAL, DOCUMENTED, IMPLEMENTED or VERIFIED. Existence of code does not imply successful execution.
4. **Safety:** never copy potential secrets, patient data or private personal material into the skill map. Source-map is a navigation aid, not a surveillance apparatus.
5. **Punctuation:** retain exact names and apostrophes; do not normalize 'Cognit into Cog'nit.
