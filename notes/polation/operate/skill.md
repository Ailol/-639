# Operate — action with a visible boundary

**Input:** data, operator, observer and scoped permission.
**Output:** proposed or executed action plus status and evidence.
**Check:** inspect input, operator mapping, output and receipt; reject claims of execution without a trace.

Preserve native syntax: data % structure; operator(...); observer(...); % is bridge, ; is boundary, * is activation. qck%note; op(pfeno); obsv(pheno'set).

Allow multiple implementations under one logical verb (gather, map, validate, execute, store) without renaming the folder to a technology.

Sources: .qck, operator.qck, qck, web3, ai-completions, Care.Ai.
Evidence: https://github.com/Ailol/qck/blob/main/readme.md and https://github.com/Ailol/operator.qck/blob/main/operator.qck

Boundary: an attractive pseudo-language is a specification, not a proven compiler.
