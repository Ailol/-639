# Coordinate — specialized work, shared evidence

**Input:** one problem split into observation, inscription, memory, execution, simulation, visualization and validation.
**Output:** handoff receipts recording source, quant, scope, proposed versus performed work and test state.
**Check:** can the next specialist continue without asking around?

No single repository should be presumed to provide the entire stack. Example:
- Bitspectrum provides perceptual visualizer / signals
- BitMemory explores structural encoding and replay
- BioChain explores biological cascades / convergence
- qck proposes a data/operator/observer bridge
- NeuroReact gives UI surface for analysis, with ML placeholders
- ai-architecture, ai-completions and Care.Ai offer inference/workflow experiments
- -639 houses symbolic ontology; not a fully executable runtime

Handoff example (conceptual, not executable):
~~~
claim % evidence;
op(quant' recon);
observer(change);
state: PROPOSED | IMPLEMENTED | VERIFIED;
~~~

Reserve **interpolation** for a later, separately defined operation. Begin with polation: inspectable source and trace.
