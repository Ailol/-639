# Represent — render truthfully on t'spektrum

**Input:** a source state, a concept, UI and optional image.
**Output:** a labeled representation with traceable origin.
**Check:** identify which features are artistic, simulated, placeholder or measured.

Sources: Bitspectrum actor/representation/pulse; NeuroReact visual components; Grain renderer; Kiff world representation; -ae-moji and ToTheDarkKnights for artistic motifs.

An illustration of nine guardians is a conceptual visualization, not nine deployed agents. A green checkmark drawn in a graphic is not a passing test. If a conversation produced a symbol, the chat remains authoritative about what the symbol meant then.

Evidence: https://github.com/Ailol/Bitspectrum/blob/main/README.md and https://github.com/Ailol/NeuroReact/blob/main/src/pages/MlPipelinePage.tsx

Constraint: art should invite exploration, not impersonate measurement.
