# Polation — logic skills from the Ailol repository lineage

**Interaction foundation:** where a person or model can check a claim without asking around. This is *polation*, not interpolation; interpolation is a future operation.

Source window: **2023-10-26 to 2026-10-26**. Start at [source-map/REPO_AUDIT.md](source-map/REPO_AUDIT.md). Skills are defined by **capability and verification**, not by C#, .NET, Python, JavaScript, Rust or a vendor.

### Rules

- Keep existing -639 folders, cipher markers, user artwork and user-authored theory unchanged. New skill notes live **only under notes/polation/**.
- Context from the actual chat should be cited or attached before it is represented as a definitive definition. No silently fabricated chat history.
- Source file ≠ running system; drawing ≠ code; commit ≠ verification; possibility ≠ permission.
- No diagnostic inference from symbolic BioChain/NeuroReact models. Respect privacy, sources and uncertainty.
- **A'llowance:** “If its ment to be; it will be.” Don't force unsupported or extreme fixes.
- One parr at a time. When evidence changes, revise interpretation openly.
