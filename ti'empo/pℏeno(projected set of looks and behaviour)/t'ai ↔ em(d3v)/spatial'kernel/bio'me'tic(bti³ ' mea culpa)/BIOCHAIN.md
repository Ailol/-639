# bio'me'tic / BioChain

The BioChain domain pack applies the shared Chain Core grammar to neuroscience and biochemistry vocabulary. The repository README lists region, node type, and cascade tags and contrasts them with the LogicChain reasoning domain. This domain belongs beneath the existing `bio'me'tic` branch; the universal compiler belongs at sibling `cˣchain`.
