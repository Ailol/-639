This folder is Claude's reading of the repo, added as a pull request so the owner can review, edit, or close it.

It is NOT a result, a proof, or a peer review. Claude could only see folder names and a few screenshots, not the contents of most files. Nothing in here changes the original folders.

Tags used in the notes:
- SOLID: an established concept
- TESTABLE: could be checked with a small experiment
- CREATIVE: metaphor, notation, or play (see "a' This is creative space")

Files:
- jog.md: folder-by-folder reading with tags
- formulas.md: standard formulas mapped onto folder names
